\section{A few words about maths}
\subsection{Inline maths}

In \LaTeX, you can use inline maths. For example, $\alpha = 3/4$ and $\varepsilon = 2 \pi$. 
The math fonts are adjusted so they don't distort your paragraph. 
This is an expression that may be too big for inline math $u(x) = \int_0^{+\infty} v(x) dx$.

\subsection{Standalone math}

You can create standalone equations as well:

$$
A = \frac{26 + \pi }{12 + \frac{13}{\Omega}}
$$

If you don't like fractions that are shrinked, you can use "dfrac":

$$
A = \dfrac{26 + \pi }{12 + \dfrac{13}{\Omega}}
$$
